# Опрос для студентов (A/B/C)

Простое веб-приложение для голосования на занятии: студенты выбирают вариант
A, B или C со своего телефона, а результаты в виде столбчатой диаграммы
транслируются на проекторе в реальном времени. Есть страница администратора
для подписи вариантов (например, указания правильного ответа) и удаления
результатов.

## Запуск

```bash
npm install
npm start
```

Сервер поднимется на `http://localhost:3000` (порт можно поменять через
переменную окружения `PORT`).

## Страницы

- `/` — страница голосования для студентов. Открывается с телефона/ноутбука,
  голос засчитывается один раз (браузер запоминает, что студент уже
  проголосовал в этом раунде).
- `/results.html` — результаты в виде графика со столбцами. Открывайте эту
  страницу на экране, подключённом к проектору — она сама обновляется
  каждые 1.5 секунды.
- `/admin.html` — панель преподавателя:
  - подписи к вариантам A/B/C (например, отметить правильный ответ) —
    сохраняются и видны студентам и на экране результатов;
  - счётчики голосов в реальном времени;
  - «Удалить результаты» — обнуляет голоса и начинает новый раунд
    (студенты автоматически смогут проголосовать заново), подписи остаются;
  - «Сбросить всё» — удаляет и голоса, и подписи.

## Как это работает

Все данные (текущий раунд, подписи, счётчики голосов) хранятся на сервере в
файле `data/state.json` и не привязаны к конкретному браузеру — это общее
состояние для всего занятия. Открывать `/admin.html` и `/results.html`
можно с любого устройства в той же сети, что и сервер.
