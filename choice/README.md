# Опрос для студентов (A/B/C) — версия для XAMPP

Папку `choice` целиком нужно положить в `C:\xampp\htdocs\`, так что итоговый
путь будет `C:\xampp\htdocs\choice`. Работает на обычном Apache + PHP из
XAMPP, отдельный сервер запускать не нужно.

## Установка

1. Запустите в панели XAMPP модуль **Apache**.
2. Скопируйте папку `choice` в `C:\xampp\htdocs\choice`.
3. Откройте в браузере:
   - `http://localhost/choice/` — страница голосования для студентов;
   - `http://localhost/choice/results.html` — результаты для проектора;
   - `http://localhost/choice/admin.html` — панель преподавателя.

Если компьютер и телефоны студентов в одной Wi-Fi сети, вместо `localhost`
используйте IP-адрес компьютера (например, `http://192.168.1.10/choice/`) —
его можно узнать командой `ipconfig` в cmd.

## Как это работает

- Все данные (раунд, подписи вариантов, счётчики голосов) хранятся в файле
  `data/state.json` на сервере — общие для всех, кто открыл страницу.
- Папка `data` закрыта от прямого просмотра через `.htaccess`
  (`Require all denied`), убедитесь, что модуль Apache `mod_authz_core`
  включён (в XAMPP включён по умолчанию).
- PHP-скрипты, обрабатывающие запросы, лежат в `api/`:
  `state.php`, `vote.php`, `labels.php`, `reset.php`, `reset_all.php`.

## Страницы

- `index.html` — голосование. Голос засчитывается один раз (браузер
  запоминает через localStorage, что уже проголосовал в этом раунде).
- `results.html` — столбчатая диаграмма с количеством и процентом голосов,
  обновляется автоматически каждые 1.5 секунды. Откройте на экране,
  подключённом к проектору.
- `admin.html` — панель преподавателя:
  - подписи к вариантам A/B/C (например, отметить правильный ответ) —
    видны студентам и на экране результатов;
  - счётчики голосов в реальном времени;
  - «Удалить результаты» — обнуляет голоса и начинает новый раунд
    (студенты автоматически смогут проголосовать заново), подписи остаются;
  - «Сбросить всё» — удаляет и голоса, и подписи.

## Требования

PHP 7.4+ (в любой актуальной сборке XAMPP уже есть) — дополнительные
расширения не нужны, используется только встроенная работа с файлами и JSON.
