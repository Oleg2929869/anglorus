# Поиск вакансий

Веб-приложение: ищет вакансии по ключевым словам сразу в нескольких агрегаторах из
каталога `job-api-catalog.xlsx`. Без зависимостей, нужен только Node.js 18+.

```bash
cd jobsearch
npm start          # http://localhost:3100
npm test
```

## Возможности

- ключевые слова;
- выбор агрегаторов (галочки; источники без ключа неактивны);
- переключатель «Только удалённая работа»;
- период публикации: **неделя** или **месяц**;
- результаты всех источников объединяются, убираются дубли по ссылке, сортировка — от новых к старым;
- под результатами — статус каждого источника (сколько найдено или текст ошибки), сбой одного
  источника не ломает остальные.

## Источники

| Без ключа | С ключом (переменные в `.env`, см. `.env.example`) |
|---|---|
| HeadHunter, Работа России, JobTech (Швеция), Remotive, Remote OK, Jobicy, Himalayas, Arbeitnow, The Muse | SuperJob (`SUPERJOB_KEY`), Jooble (`JOOBLE_KEY`, `JOOBLE_HOST`), Adzuna (`ADZUNA_APP_ID`, `ADZUNA_APP_KEY`, `ADZUNA_COUNTRY`), USAJOBS (`USAJOBS_KEY`, `USAJOBS_EMAIL`) |

`HH_TOKEN` (необязательно) — OAuth-токен hh.ru, если анонимный доступ будет ограничен.

Добавить источник: описать объект в `lib/sources.js` (`id`, `name`, `keys`, `search(ctx)`),
возвращающий вакансии в едином формате. Дата и «удалённая работа» дополнительно
фильтруются на сервере (`lib/search.js`), поэтому адаптер может вернуть лишнее.

## Важно

- Адаптеры написаны по документации из каталога, но **не проверены на живых API** —
  в среде разработки был закрыт внешний доступ (тесты идут на подменённых ответах).
  При первом запуске посмотрите строку статусов под результатами и поправьте
  адаптер, если какой-то источник вернул ошибку или изменил формат.
- У источников без поля «удалённая работа» (Jooble, SuperJob, Adzuna) признак
  определяется по тексту вакансии (remote, удалённая, дистанционная…) — возможны неточности.
- Условия использования у каждого сервиса свои (атрибуция, запрет перепубликации — см. лист
  «Каталог API»): приложение только показывает ссылки на оригинальные вакансии.
