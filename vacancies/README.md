# Поиск вакансий — версия для XAMPP (PHP)

Ищет вакансии по ключевым словам сразу в нескольких агрегаторах.

## Установка

1. Запустите в панели XAMPP модуль **Apache**.
2. Скопируйте папку `vacancies` в `C:\xampp\htdocs\vacancies`.
3. Откройте `http://localhost/vacancies/`.

Больше ничего не нужно: в XAMPP уже есть PHP и расширение curl.

## Как пользоваться

- ключевые слова + кнопка «Найти»;
- агрегаторы — галочки (источники без ключа неактивны);
- «Только удалённая» — отдельный фильтр;
- период: «За неделю» или «За месяц»;
- под результатами — статус каждого источника (сколько найдено или текст ошибки).

## Источники

- **Без ключа:** HeadHunter, Работа России, JobTech (Швеция), Remotive, Remote OK, Jobicy,
  Himalayas, Arbeitnow, The Muse.
- **С ключом** (впишите в `config.php`): SuperJob, Jooble, Adzuna, USAJOBS.

## Важно

- Адаптеры написаны по документации из каталога API, но на живых сервисах ещё не
  проверялись. Если какой-то источник показывает ошибку — это видно в строке статусов,
  код источника лежит в `api/registry.php`.
- Если Windows-антивирус/фаервол блокирует исходящие запросы, источники покажут ошибку
  подключения.
- У Jooble, SuperJob и Adzuna нет поля «удалённая работа» — признак определяется по тексту
  вакансии, возможны неточности.
- Тесты (без сети): `php tests/test.php`.
