Код для встраивания

Три способа поставить видео-форму на свой сайт — с примерами и кнопками копирования.

Перед использованием: замените FORM_ID на id вашей формы (кабинет → страница формы → плашка «Ссылка для респондентов» → /f/FORM_ID). Если приложение не на localhost:4000 — замените адрес на свой сервер. На публичном сайте обязателен HTTPS, иначе браузер заблокирует камеру.

Вариант 1 — простой iframe

Форма встроена прямо в контент страницы, вертикальная карточка 9:16.

<div style="max-width: 420px; margin: 40px auto; aspect-ratio: 9/16;">
  <iframe
    src="http://localhost:4000/f/FORM_ID"
    style="width:100%; height:100%; border:0; border-radius: 24px; overflow:hidden;"
    allow="camera; microphone; autoplay; fullscreen"
    allowfullscreen
  ></iframe>
</div>

Вариант 2 — плавающий виджет-аватар

Кружок в углу страницы, клик открывает карточку. Код вставить перед закрывающим тегом </body>.

<script src="http://localhost:4000/embed/embed.js"></script>
<script>
  window.VIDEOASK_EMBED_CONFIG = {
    url: "http://localhost:4000/f/FORM_ID",
    options: {
      position: "bottom-right",   // bottom-right | bottom-left | top-right | top-left
      avatar: "https://ваш-сайт.ру/фото.jpg",  // или уберите строку — будет иконка
      emoji: "💬",
      backgroundColor: "#1E5B3E",
      text: "Открыть видео-форму"
    }
  };
</script>

Вариант 3 — виджет с мини-видео в аватаре

В кружке играет ваше видео без звука, зациклено. Путь к файлу: кабинет → шаг с видео → адрес вида /media/media_xxxxx.webm.

<script src="http://localhost:4000/embed/embed.js"></script>
<script>
  window.VIDEOASK_EMBED_CONFIG = {
    url: "http://localhost:4000/f/FORM_ID",
    options: {
      position: "bottom-right",
      avatarVideo: "http://localhost:4000/media/media_xxxxx.webm"
    }
  };
</script>
