====================================================
VideoAsk Clone — код для встраивания на сайт
====================================================

ЗАМЕНИТЕ FORM_ID на id вашей формы!
Его видно в кабинете: страница формы → зелёная плашка
«Ссылка для респондентов» → /f/FORM_ID

Если приложение размещено не на localhost:4000 —
замените http://localhost:4000 на адрес вашего сервера
(на публичном сайте обязателен HTTPS — иначе браузер
не даст доступ к камере).


----------------------------------------------------
ВАРИАНТ 1. Простой iframe (форма встроена в страницу)
----------------------------------------------------

<div style="max-width: 420px; margin: 40px auto; aspect-ratio: 9/16;">
  <iframe
    src="http://localhost:4000/f/FORM_ID"
    style="width:100%; height:100%; border:0; border-radius: 24px; overflow:hidden;"
    allow="camera; microphone; autoplay; fullscreen"
    allowfullscreen
  ></iframe>
</div>


----------------------------------------------------
ВАРИАНТ 2. Плавающий виджет-аватар (как у VideoAsk)
Вставить перед закрывающим тегом </body>
----------------------------------------------------

<script src="http://localhost:4000/embed/embed.js"></script>
<script>
  window.VIDEOASK_EMBED_CONFIG = {
    url: "http://localhost:4000/f/FORM_ID",
    options: {
      position: "bottom-right",        // bottom-right | bottom-left | top-right | top-left
      avatar: "https://ваш-сайт.ру/фото.jpg",   // или avatarVideo: ".../видео.mp4" — или уберите строку (будет иконка)
      emoji: "💬",                     // иконка, если avatar не задан
      backgroundColor: "#1E5B3E",      // цвет кружка
      text: "Открыть видео-форму"      // подсказка для скринридеров
    }
  };
</script>


----------------------------------------------------
ВАРИАНТ 3. Виджет с мини-видео в аватаре (без звука)
----------------------------------------------------

<script src="http://localhost:4000/embed/embed.js"></script>
<script>
  window.VIDEOASK_EMBED_CONFIG = {
    url: "http://localhost:4000/f/FORM_ID",
    options: {
      position: "bottom-right",
      avatarVideo: "http://localhost:4000/media/ИМЯ_ФАЙЛА.webm"
    }
  };
</script>

Имя файла видео видно в кабинете: редактор формы →
у шага с видео откройте плеер → адрес вида /media/media_xxxxx.webm
(или пришлите мне form_id — назову точный путь).


----------------------------------------------------
БЫСТРЫЙ ТЕСТ ЛОКАЛЬНО
----------------------------------------------------

1. Сохраните код варианта 2 в файл test.html на рабочем столе
2. Замените FORM_ID на реальный id из кабинета
3. Убедитесь, что сервер запущен (npm start)
4. Откройте test.html в браузере (лучше инкогнито)
5. Внизу справа — кружок-аватар; клик → карточка 9:16

ВАЖНО: запись видео в iframe работает только если
страница-хозяин открыта по HTTPS или с localhost.
